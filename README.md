# Python Banking Program

## Overview
This is a simple command-line banking program written in Python that allows users to:
- Check their balance
- Deposit money
- Withdraw money
- Exit the application

## Features
- Secure balance management
- Input validation for deposits and withdrawals
- User-friendly menu navigation

## Prerequisites
- Python 3.x installed on your system

## How to Run
1. Clone this repository or download the `banking.py` file.
2. Open a terminal or command prompt and navigate to the script's directory.
3. Run the script using:
   ```bash
   python banking.py
   ```
4. Follow the on-screen instructions to perform banking operations.

## Usage
Once the program is running, you will see a menu with the following options:
- `1` to check your balance
- `2` to deposit money
- `3` to withdraw money
- `4` to exit the program

## Example Interaction
```
****************************************
          Python Banking Program
****************************************
1. TO CHECK BALANCE
2. TO DEPOSIT
3. TO WITHDRAW
4. TO EXIT
Enter your choice (1,2,3,4): 2
Enter amount to deposit: 1000
Your balance is: Rs 1000.00
```

## Known Issues
- The balance resets every time the program restarts. Future versions may include persistent storage.
